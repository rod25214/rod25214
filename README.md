## ✨ Recurso novo implementado
Foi adicionada uma animação de entrada dos elementos durante a rolagem da página (scroll reveal), além de efeitos hover nos cards de projetos e uma navegação responsiva.

### Como foi implementado
- O **IntersectionObserver**, no arquivo `script.js`, identifica quando cada elemento com a classe `.reveal` entra na área visível da tela.
- Quando o elemento aparece, o JavaScript adiciona a classe `.visible`.
- No arquivo `style.css`, as propriedades `opacity` e `transform` criam o efeito suave de surgimento.
- Os cards possuem transições CSS para destacar os projetos ao passar o mouse.
- O menu responsivo utiliza os componentes do Bootstrap.
